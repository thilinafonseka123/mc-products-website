# Artwork and product photograph notes

- `assets/original-photos/` contains the **10 original photos you provided** without modification, preserved for future editing.
- `public/images/products/` includes optimized WebP pictures based on those originals, including original back-of-pack instruction shots.
- `public/illustrations/*.svg`, `public/logo.svg`, and `public/favicon.svg` are hand-authored editable SVG artwork created for this project.
- The logo SVG is a design approximation, not the pixel-perfect official logo master; replace it with your official vector logo when available.
- `public/qr/` contains 3 sample QR codes in SVG / PNG plus designed labels. See README before printing.
- Lucide icons and Framer Motion code are loaded as npm dependencies with their corresponding upstream licenses.
- No font binaries are included; the UI uses appropriate fonts installed on the viewing device.
